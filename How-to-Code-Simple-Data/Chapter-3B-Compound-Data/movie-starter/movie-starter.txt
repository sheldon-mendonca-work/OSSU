;; =================
;; Data definitions:

; 
; PROBLEM A:
; 
; Design a data definition to represent a movie, including  
; title, budget, and year released.
; 
; To help you to create some examples, find some interesting movie facts below: 
; "Titanic" - budget: 200000000 released: 1997
; "Avatar" - budget: 237000000 released: 2009
; "The Avengers" - budget: 220000000 released: 2012
; 
; However, feel free to resarch more on your own!
; 


(define-struct movie (title budget released))
;; Movie is a (make-movie String Number Number)
;; interp. a movie having a title, bbudget and a release year 

(define MOVIE-1 (make-movie "Titanic" 200000000 1997))
(define MOVIE-2 (make-movie "Avatar" 237000000 2009))
(define MOVIE-3 (make-movie "The Avengers" 220000000 2012))

#;
(define (fn-for-movie mv)
  (... (movie-title mv)     ;string
       (movie-budget mv)   ;Number
       (movie-released mv)))   ;Number
;; Template rules used:
;;  - compound: 3 fields

;; =================
;; Functions:

; 
; PROBLEM B:
; 
; You have a list of movies you want to watch, but you like to watch your 
; rentals in chronological order. Design a function that consumes two movies 
; and produces the title of the most recently released movie.
; 
; Note that the rule for templating a function that consumes two compound data 
; parameters is for the template to include all the selectors for both 
; parameters.
; 


;; (Movie, Movie) -> Movie-Title
;; compare two movies and output the title of the most recently released

(check-expect (get-latest-movie MOVIE-1 MOVIE-2) "Avatar")
(check-expect (get-latest-movie MOVIE-1 MOVIE-3) "The Avengers")
(check-expect (get-latest-movie MOVIE-2 MOVIE-3) "The Avengers")

; (define (get-latest-movie mv1 mv2) "") ;stub

(define (get-latest-movie mv1 mv2)
  (if (> (movie-released mv1) (movie-released mv2))
      (movie-title mv1)
      (movie-title mv2)))
